# NV Chat

NVIDIA NIM API(`nvapi-…`) 기반 개인용 채팅 웹앱의 정적 사이트입니다.
GitHub Pages 로 배포되어 브라우저(폰·PC)에서 바로 사용할 수 있습니다.

## 기능

- 채팅 · 스트리밍 응답 · 대화 기록/검색/자동 제목
- 사진(비전 모델 자동 안내) · 텍스트/코드/PDF 내용 전달 · 음성 입력/읽어주기
- 설정(테마·글자 크기 등) + **AI 설정 도우미**(말로 사이트 수정)
- PIN 잠금(AES-GCM 암호화) · 백업/복원(JSON) · PWA(홈 화면에 추가)

## 사용 방법

1. 배포된 페이지를 엽니다.
2. **설정 → 연결** 에서 *중계 서버 URL* 과 *액세스 토큰* 을 입력합니다.
   (NVIDIA API 는 브라우저 직접 호출이 차단(CORS)되어 있어, Cloudflare Worker 중계가 필요합니다.)
3. 상단 **모델 선택** 에서 모델을 고르고 대화를 시작합니다.

> 🔒 이 저장소에는 어떤 비밀 값(API 키·토큰)도 포함되지 않습니다.
> 키는 중계 서버(Worker)의 비밀값과 브라우저 로컬 저장소에만 존재합니다.
